# NTUH ID 班表設定・產出 CSV

台大醫院感染科(ID)值班排班小工具:設定人員與班別、排定每月班表,一鍵匯出 CSV。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可(手機、電腦皆可)。若要放到網路上,可開啟本 repo 的 **GitHub Pages**(Settings → Pages → Branch 選 `main`、根目錄 `/`),即可用網址分享給科內同事。

## 功能

- **月份選擇**:西元/民國年並列,各月份班表獨立保存。
- **班別設定**:預設「值班」,可自訂多個班別(如一線、二線、會診班),每天每個班別排一位人員。
- **人員設定**:代號(員編)+ 姓名;每人可填當月**預假日期**(如 `5,12,20`),自動排班會避開。
- **排班**:逐日下拉選單手動排班;「自動排班」一鍵填滿空格——依總班數平均分配、避開預假,可勾選「避免連續兩天值班」「平均分配假日班」,**已手排的格子不會被更動**;人數不足時會放寬條件填滿並提示。
- **班數統計**:每人總班數、平日班、假日班即時顯示。
- **產出 CSV**:
  - **班表 CSV**:日期、星期、假日註記、各班別人員。
  - **統計 CSV**:每人代號、姓名、總班數、平日班、假日班、值班日期明細。
  - 皆含 UTF-8 BOM,Excel 直接開啟中文不亂碼。
- 深色模式、響應式(RWD)介面。

> 所有資料(人員、班別、各月班表)都存在你自己的瀏覽器 localStorage,不會上傳;換裝置或清除瀏覽器資料後不會保留。
