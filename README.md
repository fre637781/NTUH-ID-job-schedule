# NTUH ID 班表系統

台大醫院感染科(ID)排班系統:設定名單與每月班表,一鍵產出 12 個院內系統格式的 CSV 檔。

## 使用方式

網頁版(GitHub Pages)或直接用瀏覽器開啟 `index.html`。第一次使用請點「**匯入設定檔**」載入名單(設定檔 JSON 由排班負責人提供,**不放在本 repo**);之後資料自動存在瀏覽器 localStorage。

## 功能

1. **人員名單與值班配對**:VS/R 名單(姓名+六碼代號)、每位 R 的值班對應 VS;可增減修改,支援設定檔匯入/匯出。
2. **排班月份**:年(西元+民國)/月選單,各月份資料獨立保存。
3. **本月各區負責人**:12 個區塊(內科/外科/血腫/西址 R 與 VS、14B、5E3、急診值班 R 與 VS)下拉指定,可留空。
3-2. **ICU 負責人**:病房欄位(預設 6E1、3C、3A2、4C2、5CVI、3B2,可改名/增減)各指定一位 VS;不產出 CSV。
4. **預假/預班**:每位 R 每月的預假(不排)與預班(想排)日期,由排班負責人代填。
5. **每日值班月曆**:月曆格狀排版;選值班 R 即自動帶出對應 VS(可逐日例外改選);平日可切換國定假日;即時顯示每位 R「幾平幾假」;每位 R 有專屬底色(值班 R 與其對應 VS 同色,改選非對應 VS 則不上色);自動排班(預班優先、避開預假、平日與假日班數分開平均、盡量不連續值班──含跨月:可設定「上月最後一日值班 R」,自動從上月班表帶入)。
6. **產出 CSV**:12 檔,檔名 `區塊_班表代號_年月.csv`(如 `血腫VS_AUY_202609.csv`),含 UTF-8 BOM;可單獨或一鍵全部下載。
7. **檢視模式(手機閱讀)**:「值班表/照會表」雙分頁。值班表=單屏月曆——每格顯示日期+值班 R 的名(專屬色底),點格查看當日 R/VS 細節(含例外標注);點人名膠囊只看該員的班;可切換前後月;**另存圖片**(Canvas 繪製 PNG 直接下載,值班表反映篩選狀態)。照會表=本月各區塊 R/VS 負責人一覽(含 ICU 分層),同樣可另存圖片。由分享網址開啟時預設進入檢視模式。
8. **分享班表**:兩種連結,都只含當月班表+名單、壓縮進網址 `#` 片段、不經任何伺服器。**編輯連結**=對方載入後可完整編輯;**檢視連結**=對方僅見檢視模式(值班表+照會表),無編輯按鈕與換月箭頭(介面限制,非加密保護)。

## CSV 格式

每檔 11 欄,第 1 列表頭(班表代號/班表名稱/年/月)、第 2 列欄名(流水號、值班人員、起始日期、星期、起始時間),之後每日:

| 班型 | 平日 | 週六日/國定假日 |
|------|------|----------------|
| 平日班型(內科、外科、血腫、西址、14B、5E3) | `8` 起=本月負責人;`17` 起=空白 | `8` 起=空白 |
| 值班班型(急診/值班 R、VS) | `8` 起=本月負責人;`17` 起=當日值班人員 | `8` 起=當日值班人員 |

人員一律以代號輸出;值班 VS 檔由「R→VS 配對」自動帶出,逐日例外以例外為準。

## 隱私

- 程式碼與本 repo **不含任何真實姓名、員編或班表代號**;皆由設定檔載入、存於使用者瀏覽器。
- 分享網址的資料在 `#` 之後,瀏覽器不會將其送往伺服器。
